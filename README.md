# labs_2_semestr
Після швидкого випуску нової версії своєї операційної системи, компанія NanoSoft почала отримувати від користувачів численні повідомлення про помилки. Щоб слідкувати за прогресом виправлення помилок, команда розробників вирішила поставити велику квадратну дошку, і прикріпити до неї по листку для кожної помилки. Проте, щоб дошка вмістилася в кімнаті, потрібно, щоб вона була не надто великою. Всі N листків мають прямокутну форму і однаковий розмір W × Н. Їх не можна повертати, а також накладати один на інший. Знайдіть мінімальний розмір квадратної дошки, яка здатна вмістити всі листки. Приклад мінімальної дошки, яка може вмістити 10 листків 2 х 3
