# Лабораторна робота №8 (Варіант 2)
Завдання полягає у розробці алгоритму для пошуку максимально можливої сумарної довжини дроту, що з'єднує ряд із N стовпів, розташованих на однаковій відстані один від одного. Для кожного стовпа задана його гранична висота H, проте ми можемо довільно змінювати її в діапазоні від 1 до H. Оптимальне рішення базується на методі динамічного програмування, де для кожного стовпа розглядаються лише дві крайні точки (мінімальна висота 1 або максимальна H), що дозволяє створити найбільший нахил дроту та розрахувати його довжину за теоремою Піфагора зі складністю O(N).
