# Лабораторна робота №7 (Варіант 2)
Компанія «IoT Телеком» планує прокласти резервні оптоволоконні лінії зв'язку між своїми телекомунікаційними колодязями для забезпечення безперебійної роботи під час блекаутів. Враховуючи високу вартість матеріалів, головна мета — з'єднати всі наявні колодязі в єдину мереж, використавши при цьому мінімально можливу загальну довжину кабелю.

З математичної точки зору, це класична задача знаходження **мінімального кістякового дерева** (Minimum Spanning Tree, MST) у неорієнтованому зваженому графі. У цьому проєкті вона вирішується за допомогою алгоритму Краскала (Kruskal's algorithm) з використанням структури даних неперетинних множин (Disjoint Set Union, DSU).
### Вхідні дані
Програма зчитує дані з файлу `communication_wells.csv`. 
Файл містить пари колодязів та відстань між ними (у метрах) у такому форматі:
`K1, K2, 2000` 
*(Це означає, що між колодязем K1 та колодязем K2 можна прокласти кабель довжиною 2000 метрів).*

### Вихідні дані
Програма виводить одне ціле число:
* **Мінімальну загальну довжину кабелю**, необхідну для з'єднання всіх колодязів мережі.
* **`-1`**, якщо з'єднати всі колодязі неможливо (тобто існують ізольовані колодязі або групи колодязів, які не мають жодного можливого шляху до решти мережі).
