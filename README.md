# Лабораторна робота №6 (Варіант 2 Рівень 3)
Аутсорс компанія (один з лідерів ринку) готується до корпоративу.  HR відділ відправив опитувальник щодо видів пива, які можна буде роздавати на святі.  Переважно працівники компанії люблять небагато видів пива, і будуть дуже ображені, якщо принаймні одного з пив, які вони люблять, не буде на вечірці.  Оскільки ви - лідер ринку, то вам не можна ображати працівників. З іншої сторони, закупити усі можливі види пива - дорого. Завдання: з’ясувати скільки різних видів пива потрібно буде привезти на корпоратив.
