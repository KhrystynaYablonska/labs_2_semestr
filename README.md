# Лабораторна робота №5 (Варіант 2 Рівень 3)
Дано розмір квадратної шахівниці N, початкові координати шахового коня та координати цільової клітинки. Знайдіть мінімальну кількість ходів, необхідну коню для переміщення зі стартової позиції у цільову за стандартними правилами шахів. Поверніть знайдену мінімальну кількість кроків, реалізувавши зчитування вхідних даних з файлу input.txt (з ігноруванням текстових коментарів) та запис результату у файл output.txt, а також покрийте розв'язок модульними тестами за допомогою unittest.
